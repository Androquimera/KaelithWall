Scope: landing page pública em `docs/index.html`; mode: Persuade.

Audience: usuários de Windows com coleções próprias de wallpaper, começando por
pt-BR e permitindo leitura completa em inglês. Job: entender, confiar e baixar.

Action: baixar a release estável mais recente no GitHub. Secondary actions:
examinar o código, ler a documentação e alternar idioma.

Proof: código MIT, release v1.2.0, 25/25 autotestes, execução local, ausência de
conta/anúncios/telemetria e recursos confirmados no README. Não usar métricas de
CPU, número de usuários ou depoimentos.

Direction: “A pilha que nunca para”. A mesma gramática reaparece em três estados
durante o scroll: rodada completa, enquadramento manual e download. Memorable
moment: as imagens se afastam para provar a rodada; o editor recorta a mesma
paisagem e a pilha retorna junto da ação final.

Constraints: HTML/CSS/JS estático, GitHub Pages, sem dependências de runtime,
responsivo, teclado, redução de movimento, URL da release atual verificável.
